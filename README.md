# airig250000000247.github.io
Interactive Developer Portfolio
Overview
An interactive, animated front-end developer portfolio inspired by vibrant cartoon aesthetics and responsive design principles. Built using vanilla HTML5, CSS3, and JavaScript, this project showcases creative web design techniques, multi-layered parallax effects, and dynamic component rendering.

Live Demo and Deployment
The portfolio is deployed live via GitHub Pages at airig250000000247.github.io.

Key Features
- 3D Parallax Hero Header: A custom-built dynamic mouse-tracking parallax system with depth mapping across layers of mountains and floating clouds.
- Interactive Binder Showcase: A dynamic project carousel that switches between portfolio projects with real-time user interface updates.
- Dynamic Dialogue System: Interactive character speech bubbles that cycle through contact methods and external links when clicked.
- Fully Responsive Layout: Built using custom grid and layout systems alongside fluid typography to ensure full compatibility across mobile, tablet, and desktop screens.

Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
